# Playlist Management — CA7 starter project

This is a paired programming project. Consult the CA7 brief for the requirements, assigned responsibilities, coding restrictions and submission instructions.

## Opening the project

1. Open the `PlaylistManagement` folder in IntelliJ IDEA as a Maven project.
2. Use JDK 18 or later, as specified in `pom.xml`.
3. Run `app.PlaylistApplication` from the project root so that `sampleSongInput.txt` can be read.

The starter code compiles, but the assigned algorithms and menu actions are unfinished. Each student should complete their allocated methods, and both students should work together on integration.

The supplied `SongFileUtils` reads the file and sorts imported song tags case-insensitively before creating Song objects. New tags must be inserted in sorted order to keep binary search valid. Do not add a `setTags()` method to `Song`.

## Submission

Submit one IntelliJ project per pair with the joint contribution declaration required by the brief. `CONTRIBUTIONS.md` is an optional format for that declaration. Record incremental development using Git and be prepared for the final demonstration. No separate testing report is required.
